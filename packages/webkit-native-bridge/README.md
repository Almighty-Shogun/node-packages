# WebKit Native Bridge

Typed request and command bridge for JavaScript running inside WebKit host applications.

## 📃 Prerequisites
- **[Bun](https://bun.sh)**: >= 1.3.10

## 📦 Building
- Use the command `bun install` in the root directory to install the required dependencies.
- Run `bun --cwd packages/webkit-native-bridge build` to build the package.
