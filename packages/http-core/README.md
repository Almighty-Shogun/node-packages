# HTTP Core

Runtime-agnostic HTTP vocabulary and response helpers shared by Fetch API servers.

## 📃 Prerequisites

- **[Bun](https://bun.sh)**: >= 1.3.10

## 📦 Building

- Use the command `bun install` in the root directory to install the required dependencies.
- Run `bun --cwd packages/http-core build` to build the package.
