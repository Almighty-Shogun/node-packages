# Vite Preset

CSS Modules class name generation for Vite projects.

## 📃 Prerequisites
- **[Bun](https://bun.sh)**: >= 1.3.10

## 📦 Building
- Use the command `bun install` in the root directory to install the required dependencies.
- Run `bun --cwd packages/vite-preset build` to build the package.
