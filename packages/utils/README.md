# Utils

Shared TypeScript utilities for values, formatting, locale metadata, Luxon date helpers, serialization, and browser APIs.

## 📃 Prerequisites
- **[Bun](https://bun.sh)**: >= 1.3.10

## 📦 Building
- Use the command `bun install` in the root directory to install the required dependencies.
- Run `bun --cwd packages/utils build` to build the package.
