# Cloudflare Worker

Typed routing, worker setup, and response helpers for Cloudflare Workers.

## 📃 Prerequisites

- **[Wrangler](https://developers.cloudflare.com/workers/wrangler/)**: >= 4.0.0

## 📦 Building

- Use the command `bun install` in the root directory to install the required dependencies.
- Run `bun --cwd packages/cloudflare-worker build` to build the package.
